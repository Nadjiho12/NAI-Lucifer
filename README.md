# NAI-Lucifer

**NAI-Lucifer** is an experimental AI-powered smart drone designed to combine traditional drone control with local artificial intelligence, voice interaction, and basic autonomous capabilities.

The drone is controlled through a dedicated mobile application, allowing users to perform flight operations such as takeoff, landing, moving up, down, forward, backward, and turning. Beyond manual control, Lucifer is designed to support intelligent features such as detecting and following its user.

Its intelligence comes from a locally hosted AI system running on a PC or smartphone, connected to the drone through Wi-Fi. Users can communicate with Lucifer directly through the mobile application using text or voice commands, making interaction more natural and intuitive.

The AI system integrates several tools and capabilities, including:

- Local LLM: Understands user instructions, processes requests, and decides which actions to perform.

- Speech-to-Text (STT): Converts spoken commands into text.

- Text-to-Speech (TTS): Allows Lucifer to respond using a generated voice.

- Google Search: Retrieves online information and answers questions.

- Drone Control Integration: Translates AI-generated instructions into supported flight commands.

- Smart Follow Mode: Enables the drone to track and follow its user.

The main vision behind NAI-Lucifer is to transform a conventional drone into a personal flying AI companion that can understand natural language, access useful tools, interact with its environment, and execute physical actions.
